# Upstream copies

Unmodified `fhir.base.template` files, kept so the local overrides in `../ig-template/` can be
diffed against what they replace:

    diff template-upstream/ActivityDefinition.liquid ig-template/liquid/ActivityDefinition.liquid
    diff template-upstream/Library.liquid            ig-template/liquid/Library.liquid

They are deliberately OUTSIDE `ig-template/` — everything in there is copied into the built
template, and these are reference material, not template content.

`createArtifactSummary.xslt` used to be here too, because the overlay overrode it to give the
artifacts page a second heading level. That override is gone: the FHIR CI build refuses a local
template containing a `.xslt` file, so the page is generated by `scripts/make-groups.js` instead.
Nothing overrides that stylesheet any more, so there is nothing to diff against.
